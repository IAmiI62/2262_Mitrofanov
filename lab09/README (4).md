### Задание 1 **(2)**
*Рассмотрим следующую программу.*
```
d = {'sep': ',' , 'end': '\n'}
l = ['Утопия', 14, 'Вселенная', 25]
print (l, d)
print (*l, d)
print (*l, *d)
print (*l, **d)
```
*Объясните результаты ее работы.*

##### Решение:

Программа выводит:
```
['Утопия', 14, 'Вселенная', 25] {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 sep end
Утопия,14,Вселенная,25
```

Пояснения:

1. `print(l, d)` — два фактических позиционных параметра: список и словарь. Каждый преобразуется в строку, печатаются через пробел.
2. `print(*l, d)` — оператор `*` распаковывает список в четыре позиционных параметра, пятый — словарь целиком. Словарь печатается как строка.
3. `print(*l, *d)` — `*` применён к словарю. Итерация по словарю даёт его ключи, поэтому в список параметров попадают строки `'sep'` и `'end'`. Они печатаются как обычные значения.
4. `print(*l, **d)` — `**` распаковывает словарь в ключевые параметры `sep=','` и `end='\n'`. Элементы списка выводятся через запятую без пробелов, в конце — перевод строки (совпадает с `end` по умолчанию).


### Задание 2 **(2)**
*Напишите функцию* **sublist** *для решения следующей задачи.*

*На вход функции поступает список или кортеж и набор номеров позиций.
Функция должна составить и вернуть список из элементов, которые
находятся на этих позициях. Примеры работы приводятся ниже. Работа функции должна строго им соответствовать.*

```
>>> lst = [ 'Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
>>> sublist(lst, 0, 2, 5)
['Anna', 'Clara', 'Flora']
>>> sublist (lst)
[]
>>> sublist(lst, 0, 1, 2, 3, 4, 5)
['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```
#### Решение:

Номера позиций собираются в кортеж `*indices` (упаковка позиционных параметров). Если номеров нет, кортеж пустой и результат — `[]`.
```
def sublist(lst, *indices):
    return [lst[i] for i in indices]
```

### Задание 6 **(2)**

*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.*

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

#### Решение
```
def gen(x):
    yield x
    while x != 1:
        if x % 2 == 0:
            x //= 2
        else:
            x = 3 * x + 1
        yield x
```

### Задание 7 **(2)**

*Напишите генератор, который для заданной последовательности*
**seq** *будет задавать последовательность из каждого второго элемента* **seq**.

```
def every_other(seq):
    ...
```
*Ниже приведены примеры использования генератра.*
```
>>> print (*every_other([10, 20, 30, 40, 50]))
10 30 50
>>> print(*every_other(range(10)))
0 2 4 6 8
>>> print(*every_other(iter(range(10))))
0 2 4 6 8
>>> print(sum(every_other(map(int, input().split()))))
2 5 11 3 8
21
```

#### Решение

Цикл `for` работает и с итераторами, поэтому функция подходит для `range`, списков и `iter(...)`. Флаг переключается на каждом элементе.
```
def every_other(seq):
    take = True
    for item in seq:
        if take:
            yield item
        take = not take
```

###  Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию* **toint**? *Что возвращает эта функция?*
*Что делает функция* **wrapper**?
*Придумайте несколько примеров использования* **toint**.

#### Решение

* В `toint` передаётся функция `fun` (вызываемый объект), поэтому `toint` — функция высшего порядка (второго порядка).
* `toint` возвращает функцию `wrapper` (функции — объекты первого класса, создаются в ходе работы программы).
* `wrapper` принимает произвольное число позиционных параметров `*args`, преобразует каждый в `int` через `map(int, args)`, распаковывает результат `*` и вызывает `fun` с этими числами. Возвращает результат `fun`.

Примеры:
```
>>> toint(max)('3', '10', '2')
10
>>> max('3', '10', '2')        # без toint сравнение строк
'3'
>>> toint(pow)('2', '10')
1024
>>> toint(lambda a, b: a + b)('3', '4')
7
>>> print(toint(min)(*input().split()))
5 12 7
5
```

### Задание 3 **(5)**

*Напишите рекурсивную функцию для нахождения* **n**-о *числа Фибоначчи.*

*Функция обязательно должна работать с достаточно большими числами, например* **n = 1000** *и не
должна использовать библиотечные функции и методы.*

#### Решение

Наивная рекурсия `fib(n-1) + fib(n-2)` экспоненциальна, а линейная рекурсия на n = 1000 упирается в лимит глубины (1000). Используется метод удвоения: функция возвращает пару `(F(n), F(n+1))`, глубина рекурсии — порядка log2(n).

* F(2k) = F(k) · (2F(k+1) − F(k))
* F(2k+1) = F(k)² + F(k+1)²

```
def fib_pair(n):
    if n == 0:
        return (0, 1)
    a, b = fib_pair(n // 2)
    c = a * (2 * b - a)      # F(2k)
    d = a * a + b * b        # F(2k+1)
    if n % 2 == 0:
        return (c, d)
    else:
        return (d, c + d)

def fib(n):
    return fib_pair(n)[0]

print(fib(10))     # 55
print(fib(1000))
```
Нумерация: F(0) = 0, F(1) = 1.

### Задание 4 **(9)**

*Напишите функцию* **fastpow**, *которая будет создавать лямбда-функцию для быстрого
возведения в фиксированную степень* **n**. *Например, должен работать следующий код*
```
>>> pow10 = fastpow(10)
>>> print(pow10(2))
1024
```
*Функция* **fastpow** *в этом примере должна строить выражение для быстрого возведения в степень
по стандартному алгоритму*
* **x^1 = x**;
* **x^{2n} = (x^n) ** 2**;
* **x^{2n+1}=x*x^{2n}**;

*Например,
для* **n = 10** *может быть получена подобная строка* ```(x*((x**2)**2))**2```.

*Далее* **fastpow** *будет возвращать лямбда функцию*
```
lambda x: eval(s)
```
*При написании функции* **fastpow** *можно использовать вспомогательные функции.*

#### Решение

Вспомогательная рекурсивная функция `build` строит строку-выражение по правилам:
* n = 1 → `x`;
* n чётное → `(<выражение для n/2>)**2`;
* n нечётное → `x*<выражение для n-1>`.

```
def build(n):
    if n == 0:
        return '1'
    if n == 1:
        return 'x'
    if n % 2 == 0:
        return '(' + build(n // 2) + ')**2'
    return 'x*' + build(n - 1)

def fastpow(n):
    s = build(n)
    return lambda x: eval(s)

pow10 = fastpow(10)
print(pow10(2))    # 1024
```
Для n = 10 строится `(x*((x)**2)**2)**2`.
